# Artwork

## The atlas

The page banners are five plates of one series, *An Atlas of What AI Can
See*. They share a single art direction:

- **Ground** — the same sandstone paper as the site, so a banner reads
  as the page continuing rather than a dark box pasted onto it.
- **Ink** — Stanford cardinal at three weights plus cool grey. No glow,
  no neon, no gradients as decoration.
- **Form** — one dominant subject per plate, *generated from real
  mathematics* (projected 3D helices, an Apollonian packing built by the
  Descartes reflection formula, marching-squares level sets, sampled
  mixtures), never assembled from stock motifs.
- **Composition** — the left 44% of every plate is deliberately quiet;
  that is where the page title lands. The subject weights right and
  bleeds off the edge, so each plate reads as a detail cropped from
  something larger.
- **Series** — a hairline baseline and a letterpress plate numeral. The
  numbering is real: they are meant to be seen as a set.

| Plate | File | Subject |
|-------|------|---------|
| I · The Fold | `banners/plate-fold.svg` | Protein structure prediction |
| II · The Proof | `banners/plate-proof.svg` | Formalized mathematics (Lean) |
| III · The Cell | `banners/plate-cell.svg` | Single-cell atlases |
| IV · The Field | `banners/plate-field.svg` | Physical fields / loss surfaces |
| V · The Attention | `banners/plate-attention.svg` | The mechanism itself |

`hero-bg.svg` is the frontispiece: the same grammar pitched far quieter
and made symmetric, because the home hero carries a centered lockup.

To put a plate on a page, add the class to a banner div:

```markdown
::: {.page-banner .banner-cell}
::: {.banner-inner}
[Winter 2027]{.banner-title}
[Speakers and topics]{.banner-sub}
:::
:::
```

Available: `.banner-fold`, `.banner-proof`, `.banner-cell`,
`.banner-field`, `.banner-attention`. Giving each quarter its own plate
is the intended use.

## Regenerating

The plates are generated, not hand-drawn — edit the parameters and
re-run rather than editing SVG by hand:

```sh
cd ~/DSI/Marlowe/Seminar/tmp
uv run --with resvg-py --with pillow python gen_plates.py
cp plate-*.svg ~/GitHub/stats282/images/banners/
```

`gen_plates.py` also writes PNG previews and a contact sheet
(`plates-contact.png`) for reviewing the set together.

## Logo

`logo-mark.svg` (emblem) and `logo-lockup.svg` (emblem + wordmark) are
the *Convergence* mark: streams of measurements flowing together and
igniting. Generated by `gen_logos.py` in the same folder, which also
holds five alternate concepts and a comparison gallery.
